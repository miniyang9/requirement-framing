## 怎么写

一个文件 = 一类任务。**只写这一类任务特有的部分**：

1. **为什么 agent 做不了**（一句话）
2. **交出去的操作单长什么样**（给一个真实例子）
3. **要带回什么证据**
4. **最容易出错的那一步** ← 这才是真正值钱的经验

通用协议不重复（在 `human-executed-testing.md`）。这里只写这一类任务的特有坑。

## 什么时候补

每次人代执行做完，回头看一眼：`cases/` 里有没有这一类？

- **有** → 只补「这次新踩的坑」
- **没有** → 新建一篇，然后在上面那张表里加一行
