# 示例：三份真实的立项展开

这三个文件是 `requirement-framing` 的完整产出样例，用于对照格式与深度。

⚠️ **它们不是规格，是被研究过的案例。** 每一份都是针对一句口头需求的展开，里面还留着未确认的 `[推断]` 与未决问题。**不要把它们当成已签的规格去实现。**

| 文件 | 档位 | 用来演示什么 |
|---|---|---|
| `clash-automation.md` | T2 | 17 项横切面怎么判、L5 在"后果可承受"时的形态 |
| `trading-bot.md` | T2 | 不可逆后果（钱）如何把 L5 前移成模拟盘 |
| `github-daily-brief.md` | T1 | 小活怎么减配：只走五问，跳过 L2–L7 |

**教训**：曾经把这批文件放在工作区的 `docs/frame/` 下，结果下一个会话把它当成了"已存在的规格"直接照着实现，绕过了签字。示例与真实产物必须分路径。
